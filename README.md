# 6K音游模拟器

## ⛏️ 项目简介

6K音游模拟器是一个基于网页的游戏，帮助用户提高键盘操作的速度和准确性。游戏使用六列方块，对应键盘上的 A、S、D 和 J、K、L 键。玩家需要及时按下对应按键来消除方块，获取高分。

## 📌 技术栈

- 原生 JavaScript (ES6+)
- HTML5
- CSS3
- 模块化开发

## ✨ 特性

- 🎯 **实时统计**: 分数、准确率、CPS 和连击数
- 📊 **历史记录**: 保存最近三次游戏成绩
- ⏱️ **限时挑战**: 60秒极限测试
- 🎵 **即时反馈**: 按键音效和视觉效果

## 🚀 快速开始

进入网页 [6K音游模拟器](https://yoimiyalove.top/piano-typing-game/)

## 🎮 游戏玩法

- 使用 A、S、D 和 J、K、L 键对应六列方块
- 命中得分：+10 分
- 失误扣分：-5 分
- 连续命中可累积连击数
- 游戏时长：60 秒
